# Brightside Dental Clinic

A responsive, single-page landing page for a fictional neighborhood dental clinic in Quezon City. Built with semantic HTML, custom CSS, and vanilla JavaScript.

## Run locally

Open `index.html` in a browser. No build step, package install, or framework is required. The Google Maps embed and the map/social links need an internet connection.

## Features

- Mobile-first layout with responsive service cards, sticky navigation, and an accessible hamburger menu
- Appointment form with client-side name, phone, date, and service validation, inline error messages, and a success state
- Optional dark mode, saved in local storage
- Floating mobile call button, keyboard skip link, visible focus states, reduced-motion support, and descriptive image text
- Optimized local hero and dentist profile photography, plus a lazy-loaded map

## Before using this as a real clinic site

All clinic details, prices, reviews, telephone numbers, address, and provider information are fictional portfolio copy. Replace them with verified client information. The form is a front-end demonstration and does not transmit or store submissions; connect a consent-reviewed booking endpoint before accepting real inquiries. The map marker is an illustrative point on Maginhawa Street for the fictional suite; replace it with the clinic's confirmed address or coordinates before launch.

## Publish

This folder is a static site and can be deployed directly to GitHub Pages or Netlify. To use GitHub Pages, push these files to a repository, then select the repository's `main` branch and `/ (root)` as its Pages source. To use Netlify, import the repository or upload the folder; no build command is needed.
