# Brightside Dental Clinic — portfolio copy

## Problem → Solution → Result

**Problem:** Brightside Dental Clinic depended on Facebook inquiries and had no dedicated place to explain its services or turn visitor interest into appointment requests.

**Solution:** Built a warm, mobile-first one-page site with service prices, a dentist profile, sample reviews, an accessible appointment form with client-side validation, location details, and a prominent call action.

**Result:** Delivered a complete, lightweight static site ready for verified client details and hosting. The form demonstrates validation and a success state; a real booking endpoint, public URL, viewport screenshots, and measured Lighthouse results still need to be added before presenting those outcomes as live or verified.

## Short project description

Designed and built a responsive landing page for a fictional local dental clinic, focused on converting visitors into appointment requests. Features include a validated booking form, mobile-first layout, dark mode, and accessible navigation. Built with HTML, CSS, and JavaScript. Delivered in 1 day.
